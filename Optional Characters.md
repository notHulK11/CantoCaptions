# Character conventions

Since there are not any official organizations that sets standards for the usage of Written Vernacular Cantonese, 
we have decided to establish our own internal conventions.
By having our own internal convetions, we hope that this will make the subtitles even more useful to learners.
Having conventions allows us to achieve greater specificity, as well as train our in-house model to be more accurate.
In this way, learners can build a deeper level of understanding of the language.

We use words.hk as our primary source for characters, 
for a word to be in our mandatory conventions, it must be in words.hk.
(some words/characters from words.hk are not public, 
please visit https://jyutdictionary.com if you do not have a words.hk account)


## Other Recommended character conventions

- [Disambiguation](#disambiguation-reasons)

When the selected variant *cannot* be used interchangably with the other variants, 
we try to ensure that characters are mapped to as little words as possible, 
so learners don't get as confused when using our captions.  

- [Consistency](#consistency-reasons)

When the selected variant *can* be used interchangably with the other variants, 
we try to ensure to only use one variant, 
so learners don't get confused when using our captions.

- [Onomatopoeia](#onomatopoeia-table)

This section is for onomatopoeic words, 
and follows the same logic as the abovementioned consistency. 
Due to the vast ammounts of onomatopoeic words, we have separated it to a separate section; 
This is so our captioners and proofreaders can easily find it as well.

- [English Loanwords](#english-loanwords)

If words.hk has a character entry, 
then we prefer to use the character over the latin word. 
A general rule of thumb is that if the word before-and-after the English word is in Cantonese, 
then the sinicized Cantonese loanword version should be used instead.
